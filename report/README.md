# Report

Build `main.pdf` from this folder with `make` (needs `latexmk` and `pdflatex`). The IEEE
class and BibTeX style are included.

Tables and figures in `generated/` come from `scripts/report_tables.py` and
`scripts/report_figures.py`; edit those scripts, not the generated files.

`main_presentation.pptx` is the editable slide deck, built by `build_main_pptx.py`.
